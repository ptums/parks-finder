## Scripted VoiceOver walkthrough (about 15 minutes, human)

Setup:

1. Use macOS. Run `npm run dev:web`.
2. Open http://localhost:5173 in Safari.
3. Turn VoiceOver on with Cmd+F5.
4. Safari skips links and buttons on Tab unless "Press Tab to highlight each item" is on (Safari Settings, Advanced). Enable this setting, or use Option+Tab everywhere below that says Tab. VoiceOver navigation keys (VO+Right/Left) work in both cases.
5. At each step, record what you actually hear ("Heard:") and any problem.

Steps:

1. **Page load.** Expect the page title (descriptive, mentions parks). Then VO+Right to the main heading. Expect "Find a Park, heading level 1".
2. **Landmarks.** Open the Rotor (VO+U), Landmarks. Expect: banner; search "Search and filter parks"; main; region "Park directory"; region "Map of parks"; contentinfo.
3. **Headings.** Open the Rotor, Headings. Expect exactly: "Find a Park" level 1, "Park directory" level 2, "Map of parks" level 2.
4. **Skip links.** Tab to the first stop. Expect "Skip to results, link". Press Enter. Expect "Park directory, heading level 2" and focus there. Go back. Tab to "Skip map" and press Enter. Then press Tab once. Expect focus NOT inside the map.
5. **Search.** Tab to the search box. Expect "Search parks, search text field" (or "edit text"). Type "park" and wait about one second. Expect one announcement like "N parks shown". It must be spoken once, not once per letter.
6. **Amenities.** Tab to "Amenities (0 selected)". Expect a disclosure or group. Enter or Space expands it. Tab to the first checkbox. Expect its name (for example, "Accessible paths, checkbox, unchecked"). Press Space. Expect "checked", and later an updated count announcement ("N parks shown"). Collapse the group again.
7. **Sort.** Tab to "Sort by, pop up button" (or "combobox"). Open it with VO+Space. Choose "Rating high-low" with Down Arrow and Enter. Expect the selection to be read back. Note whether the list changes without moving focus.
8. **Reset.** Tab to "Reset, button" and press Enter. Expect one announcement: "Search and filters cleared. 12 parks shown." Expect focus to stay on Reset.
9. **No results.** Type "zzzzzz" in search. Expect "No parks match. Try removing a filter." announced once. Press Reset to recover.
10. **Directory.** Tab to the directory toggle. Expect "Hide park list, button, expanded" (desktop) or "Show park list, button, collapsed" (phone width). Press Enter and Space, and check that the state is announced. Tab through the list items. Each reads "Park name, button". For the park with no map position (REVIEW_LOG #18), listen for "Not shown on map" with a clear pause.
11. **Open details from the list.** Press Enter on "Cedar Hill Nature Preserve". Repeat with Space on another park. Expect "Cedar Hill Nature Preserve, dialog", then the heading read, with focus on the heading. Read through: description, "Amenities" list, "Address", "Hours" (verbatim text), "Size and rating", "Contact".
    - For Cedar Hill, expect "Photos not listed" and no rating line.
    - For Old Mill, expect "Not listed" wording where fields are missing.
    - For Highland Dog Park, expect the image placeholder described as unavailable ("Photo of Highland Dog Park unavailable"; REVIEW_LOG #16).
12. **Close details.** Press Esc. Expect the dialog to close, with focus on the list button that you opened it from. Repeat with the Close button. To reach "Close, button", press Tab once from the heading.
13. **Map and markers.** First use "Skip map" to confirm that it works. Then Tab into the map. Expect "Map of parks. Use arrow keys to pan." Tab again. Each marker reads "Park name, button". Press Enter: the same dialog opens. Press Esc: focus returns to that marker. Repeat with Space. Confirm that the dialog does not open twice (REVIEW_LOG #9).
14. **Map controls.** Continue with Tab. Expect "Zoom in, button", "Zoom out, button", link "Leaflet", link "OpenStreetMap". Confirm that there is nothing more in the page after the last link.
15. **Phone width.** Resize the window to about 320px (or use a phone). Repeat steps 5 to 12 once.

AI steps. Do these only on the live site or with your own key. "Once" means once.

16. **AI available.** After the page loads, expect "AI search is available." announced once, without a focus move. Reload and listen again. For about 1.5 seconds, this message must not overwrite a message that you triggered, such as a sort change.
17. **Mode radios.** Tab to the search mode group. Expect a group name and three radios: "Filters", "AI", "Both". Both is selected by default. Use the arrow keys. The selection moves, and the mode change is announced once ("Filters only", and so on). In AI mode, the standard filters should be gone from the page, not only silent.
18. **Ask.** Tab to "Ask about the parks". Type "Which park has a dog run with water fountains?" and press Enter. Expect a busy or loading state, then "Answer ready." once. The answer text must not be read word by word as it appears.
19. **Citation.** Tab to a citation button in the answer. Press Enter. The park details dialog opens, with focus on the heading. Esc returns focus to the citation.
20. **Error under the input.** Make the service unreachable or capped (or remove your key on a local server). Ask again. Expect one announcement. When you Tab or read forward, expect the message "AI search is unavailable right now. Standard search still works." directly after the input. The standard search must still work.
21. **Directory and Recenter.** In the directory, each item reads the park name, then "rated 4.7 out of 5" (or "No rating"). On the map, Tab to "Recenter map, button". Press Enter and Space. Expect the view to reset and focus to stay on the button.
