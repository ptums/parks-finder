## Scripted VoiceOver walkthrough (about 10 minutes, human)

Setup: macOS, `npm run dev:web`, open http://localhost:5173 in Safari. Turn VoiceOver on with Cmd+F5. In Safari, either enable "Press Tab to highlight each item" (Safari Settings, Advanced) or use Option+Tab instead of Tab. Record what you actually hear next to each step, and any problem.

1. **Page load.** Expect the page title (descriptive, mentions parks) and the main heading announced as "heading level 1". Note anything odd.
2. **Landmarks.** Open the rotor (VO+U), choose Landmarks. Expect banner, main, navigation or region entries for the directory and the map, each with a sensible name.
3. **Headings.** Rotor, Headings. Expect one level 1 and a logical outline (directory, details).
4. **Skip links.** Tab to the first stop. Expect "Skip to results, link". Press Enter: focus moves to the directory. Go back and Tab to "Skip map"; Enter moves into the map.
5. **Directory.** Tab or VO+Right through the list. Expect each item read as a button with the park name; listen to whether a park with no map position says something like "Not shown on map" with a clear pause (REVIEW_LOG #18). Test the collapse toggle with Enter and Space; expect its expanded or collapsed state announced.
6. **Open details from the list.** Press Enter (and repeat with Space) on a park. Expect "dialog" and the park name heading, with focus on that heading. Read through address, hours (verbatim), amenities, rating, acreage. Expect "Not listed" wording for missing fields and an image placeholder described as unavailable; check the "image, Photo of X" wording (REVIEW_LOG #16).
7. **Close.** Press Esc. Expect the dialog to close and focus to return to the park button. Repeat using the Close button.
8. **Map markers.** Use "Skip map", then Tab through markers. Each should announce a park name and button role. Press Enter, then reopen with Space. Expect the same dialog. Press Esc: focus returns to that marker. Confirm Enter opens the dialog only once (REVIEW_LOG #9).
9. **Map controls.** Check zoom buttons are labeled; check the attribution link is reachable.
10. **Live region.** Note whether anything is announced unexpectedly. Result-count announcements are not built (search cut); the live region exists but is quiet.
11. **Phone-width check.** Resize the window to about 320px and repeat steps 5 to 7 once.
