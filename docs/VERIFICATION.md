## Scripted VoiceOver walkthrough (about 15 minutes, human)

Setup: macOS, `npm run dev:web`, open http://localhost:5173 in Safari. Turn VoiceOver on with Cmd+F5. Safari skips links and buttons on Tab unless "Press Tab to highlight each item" is on (Safari Settings, Advanced), so either enable it or use Option+Tab everywhere below that says Tab. VoiceOver navigation keys (VO+Right/Left) work either way. Record what you actually hear next to each step ("Heard:") and any problem.

1. **Page load.** Expect the page title (descriptive, mentions parks), then "Find a Park, heading level 1" when you VO+Right to the main heading.
2. **Landmarks.** Rotor (VO+U), Landmarks. Expect: banner; search "Search and filter parks"; main; region "Park directory"; region "Map of parks"; contentinfo.
3. **Headings.** Rotor, Headings. Expect exactly: "Find a Park" level 1, "Park directory" level 2, "Map of parks" level 2.
4. **Skip links.** Tab to the first stop. Expect "Skip to results, link". Press Enter: expect "Park directory, heading level 2" and focus there. Go back, Tab to "Skip map", press Enter, then Tab once: expect focus NOT inside the map.
5. **Search.** Tab to the search box: expect "Search parks, search text field" (or "edit text"). Type "park" and wait about one second. Expect one announcement like "N parks shown", spoken once, not per letter.
6. **Amenities.** Tab to "Amenities (0 selected)". Expect a disclosure/group; Enter or Space expands it. Tab to the first checkbox: expect its name (e.g. "Accessible paths, checkbox, unchecked"); press Space: expect "checked" and later an updated count announcement ("N parks shown"). Collapse again.
